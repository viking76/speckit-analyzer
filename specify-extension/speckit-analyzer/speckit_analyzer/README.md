# speckit-analyzer

> **Speckit Task Analyzer** — Automated scoring, dependency analysis, and delegation packaging for speckit tasks.

Analyzes `tasks.md` files generated by speckit to score task complexity, estimate code size, calculate context requirements, identify delegable tasks, and generate minimal context packages for small LLM delegation.

## Features

| Feature | Description |
|---------|-------------|
| **Heuristic Scoring** | Zero-LLM complexity (1-10), LOC estimation, context token calculation |
| **Dependency Graph** | DAG from `Dependencies:` + Mermaid, topological sort, cycle detection |
| **Critical Path** | Longest weighted path, bottleneck detection, parallelization opportunities |
| **Context Propagation** | Upstream/downstream file context per task (configurable depth) |
| **Delegation Packaging** | Minimal context (< 100k tokens) for small LLM (4B) delegation |
| **Threshold Analysis** | Precision/recall/F1 sweep across complexity/context thresholds |
| **Statistics History** | CSV/Parquet tracking across runs for trend analysis |
| **Ground Truth Calibration** | Learns from `COMPLETED` tasks with actual implementations |

## Quick Start

```bash
# Install (from speckit repo root)
./.specify/scripts/bash/integrate-analyze.sh

# Analyze a tasks.md file
/speckit.analyze specs/001-my-feature/tasks.md

# With calibration from completed tasks
/speckit.analyze specs/001-my-feature/tasks.md --calibrate

# Custom thresholds
/speckit.analyze specs/001-my-feature/tasks.md --threshold complexity=4,context=80000

# Enrich tasks.md with scores inline
/speckit.analyze specs/001-my-feature/tasks.md --enrich
```

## Delegation to Small LLMs

Tasks with `complexity ≤ 5` and `context_tokens ≤ 100,000` are marked **delegable**. Each gets a `delegation_package/T###/` containing only what the small LLM needs:

- Task description + acceptance criteria
- Required interfaces from upstream tasks (signatures only)
- 3-5 relevant reference snippets from codebase
- Shared config snippets
- Test patterns

Total context: **typically 5k-50k tokens** — fits easily in 128k-256k context windows.

```
speckit_analyzer/
```

## Scoring Heuristics

| Metric | Method |
|--------|--------|
| **Complexity** | Keywords (async, thread, recursive...), criteria count, dependency depth, module type, pattern factor |
| **LOC** | Module velocity × estimate_days × pattern_factor × criteria_factor × deps_factor |
| **Context** | Own implementation + upstream files + specs + config (token estimate = chars/4) |

**Calibration**: When `--calibrate` is used, reads `COMPLETED` tasks' actual implementations to learn:
- Velocity per module (LOC/day)
- Pattern factors
- Complexity keyword weights
- Correlation metrics (complexity vs actual LOC, etc.)

## Threshold Analysis

Run `--sweep` or check `threshold_analysis.md` for:
- Precision/Recall/F1 at each complexity threshold (1-10)
- Precision/Recall/F1 at each context threshold (25k-500k)
- Combined 2D grid for optimal threshold selection
- Recommendation for current F1-optimal thresholds

## Statistics History

Each run appends to `stats_history.csv` and `stats_history.parquet`:
```csv
run_id,timestamp,tasks_file,total_tasks,delegable,threshold_complexity,threshold_context,avg_complexity,avg_loc,avg_context,complexity_vs_actual_loc,...
```

Enables cross-project trend analysis:
- Delegation rate over time
- Complexity/LOC/context trends
- Calibration correlation stability
- Threshold effectiveness

## Integration with speckit

### 1. Install Extension

```bash
cd /path/to/speckit/repo
./.specify/scripts/bash/integrate-analyze.sh
```

### 2. Workflow

```bash
# Standard speckit workflow
/speckit.specify "Add user authentication"
/speckit.plan
/speckit.tasks

# NEW: Analyze for delegation
/speckit.analyze

# Check results
cat specs/001-feature/analysis/task_tree.md
cat specs/001-feature/analysis/delegation_package/T###/context.md
```

### 3. Auto-Analysis (Optional)

Add to your workflow to auto-analyze after task generation:

```bash
# In your CI or post-tasks hook
/speckit.tasks && /speckit.analyze --enrich
```

## Configuration

Create `.speckit-analyzer.yaml` at repo root:

```yaml
llm:
  base_url: "http://localhost:8889/v1"
  model: "qwen2.5-4b-instruct"
  timeout: 60

thresholds:
  complexity: 5
  context_tokens: 100000
  min_estimate_days: 0.5

scoring:
  velocity_by_module:
    trainer: 120
    parser: 80
    ui: 100
    # ... overrides
  pattern_factors:
    implement: 1.0
    refactor: 1.5
    test: 0.6

context:
  max_snippets: 5
  max_snippet_lines: 50
  include_tests: true
```
